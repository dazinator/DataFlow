# Process Modeling Work Archive

This directory contains archived `plan.md` files from completed process modeling work.

## Naming Convention

Archive files use the format: `YYYY-MM-DD-issue-NNN.md`

Example: `2025-11-08-issue-169.md`

## Archive Contents

Each archived plan includes:
- Issue number and title
- Workflows that were updated
- Summary of changes made
- Test scenarios created
- Key learnings and insights
- Completion date

## Searching Archives

To find past work on specific workflows or issues:

```bash
# Search for work on a specific workflow
grep -r "Research Workflow" research/workflow-modeling/archive/

# Search for a specific issue
grep -r "#169" research/workflow-modeling/archive/

# List all archived work chronologically
ls -lt research/workflow-modeling/archive/
```

## Purpose

Archives serve as:
- Historical record of workflow evolution
- Reference for understanding why changes were made
- Examples for future process modeling work
- Source of lessons learned
